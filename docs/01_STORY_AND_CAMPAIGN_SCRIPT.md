## 🌍 Narrative Architecture & World Structure

### The Core Premise
CHUG: Shadow of Fame tells the psychological and martial journey of **Chug**, a high-profile online fighter whose immense popularity vanishes in an instant into an abstract, hostile void called **The Shadow**. Stripped of his audience, chat, and status, Chug must fight his way through layers of memory corruption, physical limits, and predatory factions known as **The Drakos** and **The Nexters**.

### The Three Worlds
1. **World 1: The Descent (Acts 1 & 2 / Chapters 1–4 / Parts 1–20)**
   - *Visual Tone*: Deep midnight void, shifting crimson glitch ruins, fractured torii gates, and oppressive silence.
   - *Theme*: Shock, loss of identity, encountering the Watcher, and meeting the unkillable Drako No.12 (Arowh).

2. **World 2: The Camp & The Broken Line (Acts 3 & 4 / Chapters 5–8 / Parts 21–40)**
   - *Visual Tone*: Warm embers, mountain ridge campfires, jagged rocky peaks, and cold moonlight.
   - *Theme*: Rebuilding Ash Camp, establishing trust, liberating trapped allies (Solo, Knight, Raevan, Sorya), and surviving Drako midnight raids.

3. **World 3: The War Gate (Act 5 / Chapters 9 & 10 / Parts 41–50)**
   - *Visual Tone*: Sunset battle horizons, marching army silhouettes, and towering abyssal blue energy gates.
   - *Theme*: Full-scale army mobilization, tactical mastery, overcoming Drako leaders (Varkul, Zeigran, Juno, Kaith), and confronting the gatekeeper **Xollonox**.

## 🛠️ Godot Cutscene & Dialogue System Architecture

### 1. Dialogue Node & Data Structure (`res://data/story.json`)
In Godot 4, all 50 parts dialogue must be stored in a typed JSON resource or custom `Resource` class with the following schema:
```gdscript
class_name StoryBeat extends Resource
@export var part: int
@export var beat_index: int
@export var speaker_id: String
@export var speaker_display_name: String
@export var dialogue_text: String
@export var stage_directions: String
@export var fight_trigger: int = -1
@export var is_glitch_effect: bool = false
@export var text_color: Color = Color.WHITE
@export var bgm_track: String = 'story'
```

### 2. Story Sequence Controller (`res://scripts/campaign/story_sequence.gd`)
```gdscript
extends Control
class_name StorySequenceController

@onready var dialogue_box = $DialogueBox
@onready var speaker_portrait = $SpeakerPortrait
@onready var speaker_label = $SpeakerLabel
@onready var body_text = $BodyText
@onready var type_timer = $TypewriterTimer

var current_part: int = 1
var current_beat: int = 0
var is_typing: bool = false
var full_text: String = ''
var char_index: int = 0

func play_part(part_num: int) -> void:
    current_part = part_num
    current_beat = 0
    advance_beat()

func advance_beat() -> void:
    if is_typing:
        body_text.text = full_text
        is_typing = false
        type_timer.stop()
        return
    
    var beat_data = GameData.get_story_beat(current_part, current_beat)
    if beat_data == null:
        complete_part()
        return
    
    if beat_data.fight_trigger > 0:
        GameSession.start_combat_encounter(beat_data.fight_trigger)
        return
    
    display_dialogue(beat_data)
    current_beat += 1
```
